# use.mahara

Loja virtual demonstrativa de moda praia, com identidade visual inspirada no verão carioca.

## Publicação

Este projeto é um site estático. Para publicar gratuitamente no GitHub Pages:

1. Abra **Settings → Pages** no repositório.
2. Em **Build and deployment**, selecione **GitHub Actions** como fonte.
3. O workflow `.github/workflows/deploy.yml` publica automaticamente o conteúdo da branch `main`.

Depois do primeiro deploy, o endereço esperado será:

`https://odeene23.github.io/use.mahara/`
